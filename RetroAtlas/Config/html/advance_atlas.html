Fixed files and execution

Samples always come from Samples/samples.csv; Compare reads Samples/comparison.csv. Advanced files always live in Config/advance_config.yaml, Config/advance_compare.yaml and Config/advance_atlas.yaml. Keys use an uppercase first letter and lowercase remaining letters; underscores and case-sensitive values are preserved. Legacy case variants are accepted, but duplicate spellings and unknown keys fail validation.

Activate your own Snakemake environment before running. CPU and total memory budgets come exclusively from the command line. Minimum: 8 cores and 32000 MB. The resource planner distributes these limits among tools. Snakemake memory is specified in MB (64000 MB = 64 decimal GB).

snakemake -s Workflow/Snakefile --cores 12 --resources mem_mb=64000 --sdm conda -p

Add -n for a dry run. Gene and tandem-repeat annotations are downloaded for the selected assembly, converted using ucsc-bigbedtobed, cached under Workflow/data/annotations/, and harmonized against validated chromosome aliases. Coordinates are never lifted between assemblies.

Cleanup: the supplied base config enables Cleanall: true, leaving only final HTML reports after all enabled objectives succeed. Set it to false to retain RDS, evidence and VCF/TSV exports. Converted CRAM-to-BAM files and indexes are always removed at complete-run success. Failed runs and partial/debug targets retain intermediates. Original inputs and shared databases are preserved.
