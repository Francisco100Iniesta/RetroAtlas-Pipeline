How to interpret this report

Condensed from the project README; technical caveats preserved

What does one row represent?

Each row describes one reconstructed biological insertion locus, not an individual raw structural-variant call. Representations from different haplotypes or technical sources can be combined when compatible.

Biological classification

Class identifies the broad retrotransposon family assigned to the reconstructed insertion, typically Alu, L1, SVA, or another supported class.

Event describes the inferred architecture of the insertion. Common values include:

  • single: one main retrotransposon component is reconstructed.
  • embedded: the retrotransposon is part of a larger inserted sequence or is embedded within additional sequence.
  • multi_same: more than one component of the same repeat family contributes to the reconstructed insertion.
  • Other event labels may be reported when the classifier detects a more complex architecture.

Completeness summarizes how much of the expected repeat model is represented in the reconstructed insertion.

  • near_full: most of the expected repeat model is reconstructed.
  • partial: only part of the repeat model is reconstructed; this does not imply the insertion is false.
  • composite_model: the reconstructed event has a composite organization that cannot be described as a simple near-full or partial copy of one repeat model.
  • not_applicable: completeness is not biologically meaningful for that architecture, including some embedded or multi-component events.

The default repeat-classification thresholds are:

  • Query coverage ≥ 80%.
  • Model coverage ≥ 80%.
  • Dominant repeat-group fraction ≥ 0.80.

If the required thresholds are not met, the assignment is considered unresolved due to insufficient evidence. Unresolved assignments are excluded from resolved-class summaries (pie chart and per-class analyses); they are not forced into a confident biological class. The insertion catalog can still retain them for auditability.

Biological verification: BIO

BIO = TRUE means double verification of poly(A/T) presence and target-site duplication (TSD) for the reported insertion. It indicates two independent supporting signatures; it is not a probability of validity and is not a requirement for a real insertion. Missing TSD evidence must not automatically be interpreted as confirmed TSD absence.

Genotype and alleles

0/1 represents a heterozygous insertion and 1/1 an ALT dosage of two. Two ALT haplotypes can have different reconstructed sizes, even with a single diploid 1/1 genotype.

Quality and coverage

Fragment Q (1–5) measures fragmentation/reconstruction-specific confidence (5 is highest); it is distinct from the original VCF QUAL and from RQ, the intra-sample reconstruction-consistency score. Neither is an absolute probability that an insertion exists.

Event coverage (%) expresses the proportion of the insertion query supported by the event reconstruction; model coverage (%) expresses how much of the reference repeat model is matched. RepeatMasker coverage (%) describes the insertion sequence covered by annotated repeat hits.

Genomic context and callability

Exon and intron refer to the selected MANE or RefSeq Select Curated transcript; promoter denotes a strand-aware upstream interval (2 kb by default); intergenic lies outside both annotated gene bodies and promoter windows. No CDS subclassification is shown.

A coverage region is callable when its coverage is positive and does not exceed the configured ratio to the applicable median. Males use separate X and Y baselines; females use the autosomal baseline for X and exclude Y. Target panels restrict the evaluated regions. Coverage callability and biological class assignment answer different questions.

Interpretation priority

Locus identity → repeat class → architecture → completeness → genotype → reconstruction quality → poly(A/T), TSD, fragmentation and local coverage. Structural complexity is a reason for caution and inspection, not automatic exclusion.

Important distinctions

BIO ≠ callability ≠ reconstruction confidence.

BIO records dual molecular support; callability evaluates sequencing coverage at a genomic interval; Fragment Q and RQ summarize distinct aspects of reconstruction reliability.

MANE transcript priority.

Use MANE Select when both Select and Plus Clinical exist for the same gene. Fall back to Plus Clinical only when Select is absent.

VCF 4.3 export

Sequence-resolved insertions when available; genotype in FORMAT/GT

The VCF preserves the native BAM/reference chromosome identifiers in CHROM and its contig headers. The report displays canonical chromosome labels; no coordinates are lifted over. The VCF uses CHROM, POS, ID, REF, ALT=REF+inserted sequence when provided by the RDS; otherwise ALT=<INS>, original VCF QUAL, FILTER, a typed INFO field and FORMAT/GT. INFO includes SVTYPE=INS, SVLEN, class, element, event, completeness, PolyA/T, TSD and their lengths, plus BIO and Fragment Q.

Reference bases and full alternate alleles are taken from the input RDS where available. For an explicit ALT allele, SVLEN reflects the sequence-resolved inserted length; RPT_SVLEN preserves the original locus-level summary, which may differ for aggregated alleles. If ALT is unavailable or cannot be anchored to REF, <INS> is emitted. Because no reference FASTA has been supplied, REF alleles have not been independently validated. TSD status stays missing when not evaluated; it is never silently changed to negative.

For downstream parsing, the R/Bioconductor package VariantAnnotation supports reading and writing typed VCF objects; V2 writes a simple VCF 4.3 text file without making Bioconductor mandatory.

VCF genotype placement

In standard VCF, GT belongs in a sample FORMAT field—not INFO. ATLAS writes it there so downstream genotype-aware tools can read the file.
